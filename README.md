# 🚀 Harsh Vardhan Pandey - Portfolio

A modern, high-performance developer portfolio built with **React**, **React Router**, and **Tailwind CSS**. It features a sleek "Midnight" dark-mode aesthetic with frosted glassmorphism elements, fully responsive layouts, and interactive UI components.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Tailwind CSS
* **Icons & UI:** Lucide React, Custom Glassmorphism Styling
* **Build Tool:** Vite

---

## ✨ Key Features

* **Dynamic Navigation:** Seamless client-side routing between Home, About, Projects, and Contact pages.
* **Modern Dark Theme:** Designed with a professional "Midnight" slate palette, subtle dot-grid backgrounds, and glowing accent gradients.
* **Interactive Project Showcase:** Direct links to live repositories highlighting backend architecture, AI integrations, and full-stack applications.
* **Responsive Design:** Fully optimized layout for mobile devices, tablets, and large widescreen monitors.
